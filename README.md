## About

A multi-page business card website for **KRASIVA** — a private massage studio run by Natalia Muradyan (Kirov, Russia).

Built from scratch: design, layout, SEO optimization, and hosting deployment. The primary goal is client acquisition through search engines and social media.

**Live site:** [krasiva-kirov.ru](https://krasiva-kirov.ru)

## Features

### 🎨 Design
- Warm pastel color palette in beige & cream tones
- Soft shadows, rounded corners, subtle gradients
- Responsive navigation with mobile burger menu
- Floating "Book Now" button on mobile devices
- "Back to Top" button on scroll

### ⚡ Interactivity
- Smooth scroll to anchor links
- Active nav highlight on scroll (Intersection Observer)
- Reveal-on-scroll animations for content blocks
- Graceful image loading error handling

### 🔍 SEO
- Schema.org structured data: `LocalBusiness`, `Service`, `Review`, `FAQPage`, `BreadcrumbList`, `WebSite`
- Open Graph & Twitter Card meta tags
- Canonical URLs on every page
- XML sitemap with priorities
- Google Search Console & Yandex.Webmaster integration

### 📊 Analytics
- Google Analytics 4 (page view tracking)
- Yandex.Metrica (webvisor, click map, accurate bounce rate)
